# 🚀 Comprehensive Render Deployment Guide for CyberShield Ledger

This guide provides a step-by-step walkthrough for deploying **CyberShield Ledger** (FastAPI Python Backend + Vite React SPA Frontend) to **[Render](https://render.com)**.

---

## 📐 Architecture Overview

On Render, the application runs as two connected services:
1. **Backend (Web Service)**: Executes the FastAPI Python app (`backend/app/main.py`) via `uvicorn`.
2. **Frontend (Static Site)**: Serves the compiled Vite + React single-page app with SPA rewrites for client-side routing.
3. **Database (Optional/Recommended)**: Render Managed PostgreSQL for persistent production data storage.

---

## ⚡ Method 1: Automated Blueprint Deployment (Recommended - 1-Click)

The repository includes a **`render.yaml`** blueprint that configures both backend and frontend services automatically.

### Step 1: Push Repository to GitHub or GitLab
Ensure your code (including `render.yaml`) is committed and pushed to your remote Git repository.

### Step 2: Create Blueprint Instance on Render
1. Log into your **[Render Dashboard](https://dashboard.render.com)**.
2. Click the **New +** button in the top right and select **Blueprint**.
3. Connect your Git repository (`CyberShieldLedger`).
4. Render will automatically detect `render.yaml` and display the services to be created:
   - `cybershield-backend` (Web Service)
   - `cybershield-frontend` (Static Site)

### Step 3: Set Environment Variables
In the Blueprint configuration screen:
- **`GEMINI_API_KEY`**: Enter your Google Gemini AI API key.
- **`JWT_SECRET`**: Auto-generated by Render (or enter your custom secret).
- **`CORS_ORIGINS`**: Automatically linked to your frontend URL.

### Step 4: Click Deploy
Click **Apply**. Render will automatically build the backend web service and compile the frontend static site.

## 🛠️ Method 2: Manual Dashboard Deployment

If you prefer to configure each service manually via the Render UI:

### Part A: Deploy the Backend Web Service

1. On the Render Dashboard, click **New +** ➔ **Web Service**.
2. Connect your Git repository.
3. Fill in the service configuration:
   - **Name**: `cybershield-backend`
   - **Region**: Choose closest to your users (e.g. `Singapore`, `Oregon`, `Frankfurt`)
   - **Branch**: `main` (or your active branch)
   - **Root Directory**: `backend`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
4. Expand **Advanced** ➔ **Environment Variables** and add:

   | Key | Value / Example |
   | :--- | :--- |
   | `PYTHON_VERSION` | `3.10.12` |
   | `GEMINI_API_KEY` | Your Gemini API key (`AIzaSy...`) |
   | `JWT_SECRET` | A secure random string |
   | `CORS_ORIGINS` | `https://cybershield-frontend.onrender.com,http://localhost:5173` |

5. Click **Create Web Service**.
6. Once deployed, copy your Backend URL (e.g., `https://cybershield-backend.onrender.com`).

---

### Part B: Deploy the Frontend Static Site

1. On the Render Dashboard, click **New +** ➔ **Static Site**.
2. Connect your Git repository.
3. Fill in the service configuration:
   - **Name**: `cybershield-frontend`
   - **Branch**: `main`
   - **Root Directory**: `frontend`
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `dist`
4. **Configure Single Page Application (SPA) Rewrites**:
   - Scroll to **Redirects / Rewrites**.
   - Click **Add Rewrite**.
   - **Source**: `/*`
   - **Destination**: `/index.html`
   - **Action**: `Rewrite`
   *(This ensures routes like `/admin/dashboard` or `/citizen/register` do not throw 404 errors on browser refresh).*

5. Click **Create Static Site**.

---

## 🗄️ Part C: Setting Up Render Managed PostgreSQL Database (Optional)

For production data persistence:

1. Click **New +** ➔ **PostgreSQL**.
2. Name: `cybershield-db`.
3. Database Name: `cybershield`.
4. User: `cybershield_user`.
5. Select **Free Plan** (or paid tier).
6. Click **Create Database**.
7. Once provisioned, copy the **Internal Database URL** (e.g. `postgresql://cybershield_user:...@dpg-...-a/cybershield`).
8. Go to your `cybershield-backend` Web Service ➔ **Environment** tab ➔ Add `DATABASE_URL` with the copied URL value.

## ❓ Frequently Asked Questions & Troubleshooting

### 1. Free Tier Cold Starts
On Render's Free tier, Web Services spin down after 15 minutes of inactivity. The first request after sleep may take ~30–50 seconds to respond as the Python container starts up. (Static Sites are always instant).

### 2. CORS Policy Blocked Errors
If API requests fail with CORS errors in browser developer tools:
- Double check `CORS_ORIGINS` in backend environment variables contains the exact URL of your frontend Static Site (e.g., `https://cybershield-frontend.onrender.com` without trailing slashes).

### 3. SPA 404 Page Not Found on Refresh
Ensure the **Rewrite** rule (`/*` ➔ `/index.html`) is set under the **Redirects/Rewrites** section of your Render Static Site settings.
